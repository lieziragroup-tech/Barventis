## antislop

For UI, copy, people, mobile layout, or code comments work, read `antislop.md` (core) and then the skill for the task:
- Core Filter: `skills/antislop/SKILL.md`
- UI / visual: `skills/antislop-ui/SKILL.md`
- Copy & text: `skills/antislop-copywriting/SKILL.md`
- People: `skills/antislop-human/SKILL.md`
- Mobile / responsive: `skills/antislop-layoutmobile/SKILL.md`
- Code comments: `skills/antislop-code/SKILL.md`

### Guidelines
1. The goal: the design should feel crafted by a designer, not generated by AI.
2. Reject technique without purpose (no unprompted purple/blue gradients, glowing shadows, nested cards, hero eyebrows, generic SaaS buzzwords).
3. Ensure proper color contrast, responsive tap targets (>= 44px on mobile), and mathematical spacing hierarchy.
